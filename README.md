**Plan every cable, rack and route before the show.**

Flypack is an open-source, agent-first planner for live production crews: video, network,
signal and audio patching, racks, and cable runs measured on the venue's own floor plan, with an
MCP server so you can plan a show by talking to an agent.

It's early. There is no application yet; the plan is in [docs/PRODUCT.md](docs/PRODUCT.md) and
the research behind it in [docs/research](docs/research/).
